# Keyboard shortcuts

Click the keyboard icon in the top bar, or press **F1** / **Ctrl+/**, for the full list. Disabled modules are omitted. On macOS use Command instead of Ctrl; some laptops require Fn for function keys.

| Keys | Action |
| --- | --- |
| F8 | New sales invoice |
| F9 | Open purchase bills |
| F6 | Open payment receipts |
| F3 | Focus search in sales list, inventory, customers or purchase bills |
| Ctrl+K | Search records and commands |
| Shift+1 / Shift+2 / Shift+4 / Shift+6 | Dashboard / inventory / customers / reports |
| Shift+B / Shift+R / Shift+X / Shift+C / Shift+G | Purchases / receipts / expenses / cash book / GST returns |
| Ctrl+S | Save invoice |
| Ctrl+P | Download invoice PDF |
| Ctrl+Enter | Add invoice item row |
| Ctrl+Shift+D | Duplicate last invoice item |
| Ctrl+Shift+L | Lock app, if a PIN is configured |
| Tab / Shift+Tab | Next / previous field |
| Escape | Dismiss a dialog |

Navigation keys work outside text inputs, dropdowns and editable fields. Click a heading or tab to a button before using them. Invoice actions are limited to the invoice editor and paused while a dialog is open. Shortcut navigation away from an edited invoice uses its save/discard/cancel dialog. F9 and F6 open the respective pages; they do not submit transactions. Ctrl+N remains a legacy alias for F8, but browsers may reserve it for a new window.

## Research and choices

Reviewed official documentation for representative accounting products, rather than claiming an exhaustive market ranking:

- [TallyPrime](https://help.tallysolutions.com/tally/keyboard-shortcuts-tally-prime/): dedicated voucher keys and keyboard navigation.
- [BUSY](https://busy.in/faqs/what-are-the-keyboard-shortcuts-available-in-busy-answerid-65802/): separate general and voucher-entry shortcuts.
- [Zoho Books](https://www.zoho.com/us/books/help/getting-started/keyboard-shortcuts.html): Shift-based page navigation and an in-app reference.
- [QuickBooks Online](https://quickbooks.intuit.com/learn-support/en-us/help-article/product-setup/keyboard-shortcuts-quickbooks-online/L49aUqVh2_US_en_US): field navigation and browser shortcut considerations.
- [Marg](https://care.margcompusoft.com/margerp/sale/179360/utils/trees): shortcut reference available during billing.

AUTO-GST combines these patterns with its existing shortcuts. It does not copy desktop combinations that would interfere with selecting text, refreshing the browser, or ordinary typing. Navigation to pages with no equivalent module was not added.
